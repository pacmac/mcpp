# Plans

Each subfolder defines a discrete unit of work — a feature, fix, or change. Read the subfolder relevant to your current task.

| File | Answers |
|------|---------|
| **WHAT.md** | What are we building and why? (requirements, scope, constraints) |
| **HOW.md** | How will we build it? (approach, phases, risks, decisions) |
| **ACTIONS.md** | What do I need while working? (commands, file layout, gotchas) |
| **TASKS.md** | What's done and what's left? (TODO, in progress, done) |
